🏨 Projet de Gestion de Réservations Hôtelières – Langage C
📌 Description
Ce projet est une application console développée en langage C permettant de gérer les réservations hôtelières. Il offre aux utilisateurs la possibilité de consulter la disponibilité des chambres, effectuer des réservations, annuler des réservations, et gérer les informations des clients.
L’objectif principal de ce projet est de mettre en pratique les notions de structures, fichiers, tableaux dynamiques, et gestion mémoire en C.

✨ Fonctionnalités
🔍 Affichage des chambres disponibles
🧾 Réservation d’une chambre
❌ Annulation d’une réservation
👤 Gestion des informations clients
🗃️ Sauvegarde et chargement des données via des fichiers
📊 Statistiques sur les réservations

⚙️ Technologies utilisées
Langage : C
Compilation : gcc
Données : Fichiers .txt pour la persistance
